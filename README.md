# Mino 官方插件索引

DSH Discover 页用的插件市场索引（plugin-market-index format 1）。

**在 Mino/DSH 里添加（二选一，内容相同）：**

- `https://mino.baby/plugins/index.json`（主源，国内直连）
- `https://cdn.jsdelivr.net/gh/694410194/mino-plugin-index@main/index.json`（镜像）

入口：Plugins → Discover → Manage index sources → 粘贴索引地址。

由官方 `dsh-plugin-market-generator` 从 [694410194/mino-plugins](https://github.com/694410194/mino-plugins) 生成；插件版本随发版更新。

## 相关

- **Mino 客户端官网与下载**：https://mino.baby ——基于 DeepSeek Harness 的桌面 AI 助理，一个账号使用 Claude、GPT、DeepSeek、Grok 等多家大模型，插件市场已内置本索引。
- 手动安装包（.tgz）：[694410194/mino-plugin-releases](https://github.com/694410194/mino-plugin-releases)
