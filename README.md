# Mino 官方插件索引

DSH Discover 页用的插件市场索引（plugin-market-index format 1）。

**在 Mino/DSH 里添加：** Plugins → Discover → Manage index sources →
`https://raw.githubusercontent.com/694410194/mino-plugin-index/main/index.json`

由官方 `dsh-plugin-market-generator` 从 [694410194/mino-plugins](https://github.com/694410194/mino-plugins) 生成；插件版本随发版更新。
